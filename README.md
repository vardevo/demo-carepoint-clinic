# CarePoint Clinic — Clinic Appointment Website

A complete, production website for a medical clinic, with online appointment booking and an admin dashboard. Built and deployed solo as a demonstration of a full healthcare small-business web product.

**Live demo:** https://clinic.vardevo.com

## What it does

- **Marketing site** — landing page and services for a clinic
- **Appointment booking** — patients request appointments; requests are saved to a database instantly
- **Admin dashboard** — clinic staff view and manage all appointment requests
- **24/7 intake** — every request is captured, so no patient enquiry is lost

## Tech stack

- Front end: HTML5, CSS3 (custom, responsive)
- Backend / database: Supabase (PostgreSQL)
- Hosting: Vercel

## Pages

| Page | Purpose |
|------|---------|
| `index.html` | Landing page |
| `services.html` | Clinic services |
| `book.html` | Appointment booking (writes to Supabase) |
| `admin.html` | Staff dashboard to view/manage appointments |
